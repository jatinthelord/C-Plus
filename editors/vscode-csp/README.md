# C+ VS Code file icon

This folder is a minimal VS Code extension for C+ source files.

It registers the `.csp` extension as the `C+` language and contributes the
`C+ File Icons` file icon theme.

## Install locally

1. Open this folder in VS Code.
2. Press `F5` to launch an Extension Development Host.
3. In the development host, run `Preferences: File Icon Theme`.
4. Select `C+ File Icons`.

For a packaged installation, install the folder as a VS Code extension or
package it with the VS Code Extension Manager (`vsce package`).
