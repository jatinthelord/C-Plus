# C+ Programming Language Ecosystem
Blazing fast native execution speed (252ms integer benchmark targets) with zero runtime bloat.

## Native GUI applications

`<cspWindow>` provides UTF-8 text, DPI-aware windows, buttons, labels, text
boxes, check boxes, progress bars, responsive resizing, keyboard and close
events, dialogs, themes, and an application event loop. See `main.csp`.

```powershell
cspc build main.csp -o app.exe
```
