Frequently asked questions

How do I compile a program?

Run cspc hello.csp -o hello.exe from the project root.

How do I install libraries?

Use csx --prefix .csx install cp-system.

Can I inspect generated output?

Use --emit-cpp, --emit-c, --emit-rust, or --emit-llvm.

Where are errors reported?

The compiler reports source locations and the website has linked error pages.
